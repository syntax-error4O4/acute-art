# What is Procedural Art?
* Procedural art is art generated from code! Its even used for generating terrains in video games! The way it works is that there are a set of defined rules/constraints written by the programmer based on which a piece is made. It could be static or have a different look for each generation. It can have movement too!
* The piece above is made using p5.js. It contains two different palettes and the ability to download the generated image. Each generation is different.
